# 윙토언어 — 숲속 마을 도구 UI 리디자인

기존의 **텍스트 변환, 배경·색상 설정, PNG 다운로드, 자모 대응표** 기능은 유지하면서 화면만 전면적으로 개선한 버전입니다.

## 실행 방법

```bash
npm ci
npm run dev
```

브라우저에서 개발 서버 주소를 열면 됩니다. 프로덕션 빌드는 아래 명령으로 확인할 수 있습니다.

```bash
npm run build
```

## 반영한 UX 개선

| 영역 | 변경 사항 |
|---|---|
| 전체 화면 | 따뜻한 아이보리 바탕, 세이지·하늘·복숭아 계열, 둥근 카드와 절제된 자연 장식 |
| 입력 | 카드형 입력창, 친근한 안내 문구, 글자 수, 명확한 키보드 포커스 |
| 변환 | 주요 버튼 강조, 짧은 변환 상태, 중복 클릭 방지 |
| 꾸미기 설정 | 배경·무늬·기호 색 라벨, 스와치 이름, 체크 표시 및 선택 상태 |
| 결과 | 중심형 결과 프레임, 완화된 투명 체크무늬, 빈 상태 안내, 가로 스크롤 |
| PNG 저장 | 활성·비활성 상태, 저장 완료 안내, 기존 PNG 생성 방식 유지 |
| 도움말 | 입력부터 저장까지 4단계 안내와 접을 수 있는 자모 대응표 |
| 접근성 | 버튼·스와치의 이름과 선택 상태, 포커스 링, 모션 감소 환경 대응 |
